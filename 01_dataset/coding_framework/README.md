# Coding Framework


This folder contains the complete coding framework used to extract and code data for this review. 

It provides the operational definitions and coding rules for every variable reported in the manuscript and supplementary tables.

## Contents

| File | Description |
|---|---|
| `Coding_Framework.xlsx` | Variable inventory and coding format specification: all 56 variables grouped into 9 domains, each with its domain-level coding rule and coding format (binary 0/1, ordinal 0/1/2, integer, or text label). |
| `Operational_Framework.xlsx` | Operational definitions of the 56 variables: what each variable captures, the full coding rule, and explicit boundary criteria for ambiguous cases. |
